# 用 TypeScript 复刻 Minecraft（v7）：方块状态

> 本文是 mc-replica 系列的第 v7 篇。到 v6 为止每种方块只有一个样子：原木都是竖着的，藤蔓不知道贴在哪一面，
> 雪下面的草方块还是绿的。v7 给方块加上“状态”，并且让地物生成的每一格连属性都和原版对上。
> 开发日志见 [../notes/v7-notes.md](../notes/v7-notes.md)。

## 一、方块和方块状态

原版里“方块”和“方块状态”是两回事。橡木原木是一种方块，它有三个状态：`axis=x`、`axis=y`、`axis=z`。
树叶有 `distance`（1~7）× `persistent` × `waterlogged`，一共 28 个状态。世界里每一格存的其实是状态。

原版所有方块加起来约 2.7 万个状态，每个有一个全局编号。v1 讲调色板时说过，调色板的“直接模式”每格存的就是这个编号，要 15 位——
当时我们只有十几种方块，用不上。v7 终于用上了。

## 二、编号从哪来

属性和取值没有手抄。原版服务端有一个“数据报告”模式，会把每个方块的属性、取值、全局编号写进 `blocks.json`。
我们用到的 234 种方块里有 102 种有属性，生成一个小表 `stateDefs.json`。

编号规则只有两条：

- **方块 b 的默认状态编号就是 b**。所以 v6 以前所有写 `BlockType.stone` 的地方不用改，写进去的就是默认状态
- 其余状态排在所有方块后面。同一个方块内部的顺序和原版一样：属性按定义顺序，最后一个变得最快

一共 2372 个状态，12 位。区块、网格、光照里存方块的数组都从 8 位换成 16 位；所有“按方块查”的表
（是不是实心、什么形状、什么纹理、发多亮的光）都扩展成“按状态查”。这一步改了二十多个文件，
好在 TypeScript 的类型检查能找出每一个还在用 8 位数组的地方。

## 三、按状态和原版对照

对照工具原来只比方块名，现在同时比完整的状态字符串，比如 `minecraft:oak_leaves[distance=3,persistent=false,waterlogged=false]`。
v6 的代码跑一遍，方块一致 99.67%，状态一致只有 99.50%——位置对上了、属性不对的有 2.6 万格，几乎全是树叶的 distance。

## 四、树叶的 distance

树叶的 distance 是“沿着树叶走几步能到原木”，离原木太远（7）的树叶会掉落。原版放完一棵树以后，
在这棵树的包围盒里从原木出发一层一层往外算（`TreeFeature.updateLeaves`）。照抄以后，森林里一半的树叶还是比原版大 1。

原因在“包围盒”：盒子外面可能有别的树的原木离得更近，但算的时候看不到。原版会给盒子边上的树叶安排一次“方块刻”，
刻到的时候 `distance = min(六个邻居) + 1`，变了再通知邻居……一路传下去。最后的结果基本就是“全局最短路”。

先用原版自己的方块验证这个猜想：按最短路算，98.6% 的树叶和原版存的值一样；剩下 1.4% 是原版没有刻到的。
于是加了一步“落定”：区块和周围 8 个区块都生成好以后（游戏里正好是 v6 算光照的那一步），按最短路改一遍树叶。
森林里的树叶从 41% 一下到了 100%。

## 五、其他状态

大部分状态写在地物的配置里——原来我们读配置时只取方块名，把 `Properties` 丢掉了。带上以后，洞穴藤蔓的浆果、
粉红花簇的朝向和数量、蘑菇柄的面一下子都对上了。剩下的要照着原版代码一个一个补：

- **藤蔓**：树干上的藤蔓贴在朝着原木的那一面，树叶上垂下来的藤蔓也一样
- **发光地衣、幽匿脉络**：v5.1 时我们没有状态，用一张临时表记“贴在哪几面”，跨区块就丢了。现在直接存在状态里
- **两格高的植物**：上半格 `half=upper`
- **雪地草方块**：下雪的时候，原版顺手把下面的草方块设成 `snowy=true`
- **滴水石锥**：从根到尖依次是 base、middle、frustum、tip；上下两根正好连起来时尖是 tip_merge
- **大蘑菇**：菌盖哪几面是“皮”（外面）、哪几面是“肉”（里面）
- **横着的原木**：花式橡树、樱花树的树枝按方向设 axis
- 还有海带的 age、竹子的叶子、海泡菜个数、珊瑚扇和紫水晶芽的朝向、化石骨块（转 90° 时 x、z 轴互换）、
  紫颂植物的连接、末地柱铁栏杆的连接、地牢箱子的朝向……

结果：方块一致还是 99.67%，状态一致从 99.50% 到了 **99.66%**；位置对上的格子里，属性不一样的从 0.17% 降到 0.016%。
剩下的大多是附近的树本身位置就不一样（树叶的 distance 跟着变）。

## 六、看得见的变化

状态不只是数字：

- 光照按状态取：有浆果的洞穴藤蔓发光（14），海泡菜越多越亮，没有面的发光地衣不发光
- 横着的原木两头是年轮；雪下面的草方块侧面是白的；蘑菇方块的“里面”是另一种颜色；两格高的花下半格只有茎和叶
- 放原木时按点的那一面定朝向；F3 的“准星”一行显示完整状态
