# v3 开发日志

技术解析见 [../articles/v3-含水层与流体.md](../articles/v3-含水层与流体.md)。

## 目标

- 地下的水、岩浆按原版含水层生成，位置和原版一致
- 水和岩浆有原版的流动状态，会流动；岩浆遇水凝固
- 流动的水推人；岩浆里能移动

## 过程

1. **含水层**：对照原版 1.21.1 的 `Aquifer.NoiseBasedAquifer` 逐行移植，变量名尽量保留原版的单字母（o/p/q/r、s/t/u/v），
   方便以后对照源码。
   - noise_settings 解析加上 `aquifers_enabled`、`default_fluid`。demo 的简化地形没开含水层，走“全局流体”。
   - 判断深暗之域时，erosion / depth 在原版是通过 NoiseChunk 求值的（`flat_cache` 对齐到 4 格），
     写了 `chunkLocal()` 模拟“这个区块的 NoiseChunk”。
   - 预估地表高度（1.21.1 的写法：从顶往下每 8 格查一次 initial_density_without_jaggedness）按 quart 列缓存，
     缓存放在 Worldgen 上，同一个 Worker 生成的区块共用。
2. **性能**：第一版每个区块的时间翻倍。按原版的做法把格子缓存换成定长数组（预先按区块范围分配），
   结果不变，原版主世界每个区块约 83 → 102 ms。
3. **方块 ID**：每种流体状态一个 ID（水 7、16~23；岩浆 15、24~31），加了黑曜石 14。
   `BLOCKS` 从 Record 改成数组，`BLOCK_BITS` 变成 5。
4. **流体流动**（`FluidTicker`）：照原版 FlowingFluid 的 tick / spread / getSpread / getSlopeDistance 写。
   测试一次写了 7 条规则，除了“角高度”那条全过——那条是我的预期写错了：源四周是空气时角会往下塌，原版也是。
5. **渲染**：顶点坐标精度改成 1/256 格；流体面的 key 带上角高度，只有平的才合并；岩浆进 opaque。
6. **移动**：MoveWorld 从 `isWater` 改成 `block`，水 / 岩浆的深度、水流方向都按原版算。
7. **浏览器里的坑**：
   - 截地下湖时湖面上有一道竖着的水墙。dump 方块数据发现两边都是水，位置正好在区块边界：
     区块加载后含水层边上的水开始流动，主线程重建 section 时邻居区块还没加载、被当成空气，画出了侧面，
     邻居加载后也没有重建。加了 `staleSections`。
   - 写文章对比图时以为 v2 的洞穴“全是水”，截图一看是干的——v2 只在每一列最高的石头上面填水。改了文章和注释。
