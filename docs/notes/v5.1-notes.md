# v5.1 开发日志

技术解析见 [../articles/v5.1-其余地物与洞穴.md](../articles/v5.1-其余地物与洞穴.md)。

## 目标

- 雕刻器：洞穴（cave）、峡谷（canyon）
- 其余全部主世界地物：花草、湖、泉、冰刺、冰山、晶洞、滴水石、苔藓 / 黏土地块、杜鹃树根系、幽匿、珊瑚、地牢……
- 每一批都和原版 1.21.4 服务端生成的“完整地物”存档对照

## 过程

1. **雕刻器**（`worldgen/carver/Carver.ts`）：每个区块看周围 ±8 个区块起头的洞，起头区块的雕刻器来自 (sx·4, 0, sz·4) 的噪声群系，
   种子 `setLargeFeatureSeed(seed + 序号, sx, sz)`，用的是旧的 48 位 LCG（写了 `FastLegacyRandom`，两个 24 位数拼，比 bigint 快 3 倍）。
   挖到的格子交给含水层决定空气 / 水 / 岩浆，露出来的泥土换成地表顶层方块。
   - 一开始什么都没挖：少了 `overworld_carver_replaceables` 标签
   - 之后和原版只开雕刻器的存档对照：出生点 99.996%（差 59 格流动的水），恶地、沼泽 100%；每个区块约 3 ms
2. **方块**：93 种新方块（花草、珊瑚、滴水石、紫水晶、幽匿、苔石、刷怪笼、箱子……），一共 202 种（上限 256）。
   纹理还是代码画的；海草、海带、珊瑚、海泡菜原版总是“含水”的，这里直接当水源（网格和物理都按水算，流体不会把它们冲掉）。
3. **方块标签**：v5 是手写的，v5.1 改成 `tools/vanilla/gen-tags.py` 从原版 jar 展开（嵌套的 `#标签` 都展开），
   写成 `feature/blockTags.json`，45 个标签。
4. **地物**：先用 `javap` 找到每个地物类（地物名字符串和 `new 类名` 在注册类里挨着，一次全部对上），再逐个照字节码写。
   - 植物（`vegetation.ts`）：random_patch / flower、simple_block、block_column、海草、海带、海泡菜、竹子、藤蔓、
     multiface_growth（发光地衣、幽匿脉络）、vegetation_patch / waterlogged_vegetation_patch、root_system
   - 地形（`terrain.ts`）：lake、spring_feature、ice_spike、iceberg、blue_ice、forest_rock、desert_well、monster_room、
     underwater_magma、geode、pointed_dripstone、dripstone_cluster、large_dripstone
   - 幽匿（`sculk.ts`）：sculk_patch + SculkSpreader（世界生成版）
   - 珊瑚（`coral.ts`）：珊瑚树、珊瑚爪、珊瑚蘑菇
   - 噪声方块提供者：noise_provider（花林）、noise_threshold_provider（平原）、dual_noise_provider（草甸）
5. **对照**：`make-world.py full` 生成原版完整地物存档，40 个区域（v5 的 21 个 + 新找的 19 个群系），
   `tools/vanilla/diff-areas.ts` 按区域比较并列出每种方块的一致率，`probe.ts` 看某种方块哪几格对不上。
6. **找到的错**：
   - 发光地衣多了一倍。字节码显示原版的“往外找”写的是 `setWithOffset(origin, d)`：每次都是起点旁边那一格，并不会越走越远。
     照抄以后 98.6% 一致（之前 55%）
   - 蘑菇多了 6 倍：原版要求亮度 < 13（或者长在菌丝、灰化土上）。生成地物时光照还没算完，原版取到的值和生成顺序有关；
     试了三种模型，“全都算亮”最接近存档（露天的沙滩、草地上不长）
   - 两格高的植物、海草高的那种、小垂滴叶都要上面一格空着；我们的方块没有“上半 / 下半”，两格放同一种方块
7. **性能**（都和原版结果完全一样）：
   - 气候参数表查找加上“上一次的结果当上界”（原版 RTree 也这么做）：7 µs
   - 气候的 5 个平面参数（温度、湿度、大陆性、侵蚀、奇异度）按列缓存，只有深度随 y 变：一次采样 23 → 6 µs。
     缓存前会检查数据包里这几个函数确实和 y 无关（`y_scale = 0` 的 shifted_noise、flat_cache）
   - BiomeManager 的抖动只和角点有关，按角点缓存：每个方块位置少算 72 次 64 位乘法
8. **渲染**：藤蔓、发光地衣、幽匿脉络是“多面”方块，贴着旁边每个实心方块的面画一片（我们的方块不记贴在哪面，
   就按“哪几面挨着实心方块”画），一面都没有时画成十字。

## 和原版不一样的地方（原因）

- **生成顺序**：大地物（树、滴水石簇、幽匿、苔藓地块）会跨区块，原版后生成的区块能看到先生成的邻居放下的东西，
  而原版自己的先后顺序取决于加载顺序。我们用 4×4 区块的“装饰区域”，区域之间互相看不到。
  样本区域跨了区域边界的地方（比如丛林 82~85 号区块正好被 84 切开）树就对不上，进而影响藤蔓、可可果。
- **幽匿**：蔓延过程要知道每格脉络贴在哪几面；我们只在地物运行期间记下来，之前放的脉络按“周围哪几面实心”猜。
  深暗之域本身的样本区域几乎一致，其他群系地下的深暗之域差得多。
- **方块状态**：没有朝向、含水、上下半、年龄……（v7 做方块状态）。所以苍白苔藓地毯不会往上长、气泡柱没有、
  滴水石锥都是同一种形状。
- **化石**（骨块）：要读原版的结构模板文件，v5.1 没做。
- **流体**：原版存档是 forceload 跑过一会儿的，泉水已经流开了；我们在区块加载后才开始流。
