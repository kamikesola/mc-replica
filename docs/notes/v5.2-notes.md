# v5.2 开发日志

技术解析见 [../articles/v5.2-下界、末地与收尾.md](../articles/v5.2-下界、末地与收尾.md)。

## 目标

v5.1 之后地物还没做完：

- 主世界：化石、气泡柱没有；滴水石锥只有 45% 和原版一致、幽匿 20% 多，要查清楚是代码错还是生成顺序
- 下界、末地：v5 只做了主世界，这两个维度的地物、下界的雕刻器都没有

## 过程

1. **单个地物的对照存档**：`make-world.py` 加了 `only:a,b` 模式（只留列出的地物，保留雕刻器），
   `tests/featurePacks.ts` 加了同样的 `onlyPack`，`diff-areas.ts --features`、`probe.ts FEATURES=` 用它对照。
2. **滴水石**：分开看三种地物——大钟乳石 100%、滴水石锥 99.99%，只有滴水石簇对不上，而且是“整簇”对不上。
   - 读字节码找到一处漏掉的条件：放水洼时脚下也要是石头或水（`canPlacePool` 最后一行）
   - 剩下的差别：用 `ChunkSource.isolated`（新加的调试开关，每个区块只放自己的地物）确认是本区块的随机数序列走偏了。
     滴水石簇会读周围的地形，邻居区块先放的簇会改变“柱子”的扫描结果，随机数用量跟着变，之后这个区块的所有簇都挪了位置。
     同一个区域我们自己按两种顺序装饰，结果就差 12%；原版的世界生成是多线程的，顺序本身就不固定，没法逐格一致
   - 幽匿同理（深暗之域的样本区域本身几乎一致）
3. **化石**：要原版 jar 里的结构模板（`data/minecraft/structure/fossil/*.nbt`）。新工具 `structures-to-json.ts` 转成 JSON
   放进 `datapacks/vanilla/structure/`（和其他原版数据一样不进 git），再加上 `worldgen/processor_list/fossil_*.json`。
   实现了 `StructureTemplate.placeInWorld` 里化石用到的部分：旋转、零点、包围盒、三种处理器（腐烂、保护、规则）。
   只放化石的存档里逐格一致；完整存档里骨块 99.8%。
4. **气泡柱**：岩浆块、灵魂沙上方连着的水源都变成气泡柱（原版是加载后第一次方块刻做的）。完整存档里 97.7%。
5. **下界和末地的地形本身是错的**：做下界地物之前先比较了关掉地物的存档——下界只有 60% 一致。原因：
   - 所有维度共用一个 `RandomState`。原版按 noise_settings 的 `legacy_random_source` 选：下界、末地用旧的 LegacyRandomSource，
     温度、湿度是特殊的“旧下界群系噪声”。改成按维度选以后，群系 1024/1024 一致，地形 **100%**
   - 地形的实心方块一直写死成石头，现在用 noise_settings 的 `default_block`（下界岩、末地石）
   - 末地的群系：原版不是查气候参数表，而是 `TheEndBiomeSource`：主岛之外按区块中心的 erosion 分成高地、中地、小岛、荒地
6. **下界雕刻器**：`nether_cave` = 洞穴雕刻器的变体（起点少、更粗、更扁），不管含水层，y ≤ 31 填岩浆、上面是空气。
7. **下界地物**（`feature/nether.ts`）：萤石、玄武岩柱、玄武岩柱群、三角洲、替换团块、分散矿石（远古残骸）、巨型菌、
   下界植被、垂泪藤、缠怨藤；放置修饰器 `count_on_every_layer`（一层一层往下数地面）。
   `BlockPos.withinManhattan` 的遍历顺序照抄（三角洲、替换团块要用）。
8. **末地地物**（`feature/end.ts`）：黑曜石柱（10 根柱子的高度由世界种子打乱）、出生平台、末地小岛、紫颂植物、折跃门。
   顺便修了 `fixed_placement`：原版只留在当前区块里的位置，之前每个区块都放一次。
9. **32 种新方块**（共 234 种）：下界岩、灵魂沙 / 土、玄武岩、黑石、两种菌岩 / 菌柄 / 疣块、菌光体、菌、菌索、藤、火、
   末地石、紫颂、铁栏杆、折跃门、气泡柱。气泡柱“只画水”（新形状 none）。
10. **游戏里**：下界、末地有自己的天空色；下界出生时从基岩天花板下面找落脚点。
