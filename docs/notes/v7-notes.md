# v7 开发日志

技术解析见 [../articles/v7-方块状态.md](../articles/v7-方块状态.md)。

## 目标

到 v6 为止每种方块只有一个样子：原木都是竖着的，树叶没有 distance，藤蔓不知道贴在哪一面，两格高的花上下一样，
雪下面的草方块不是雪地草方块……原版存档里，地物生成的方块有约 16 万格不是默认状态。v7 要做：

- 方块状态系统：属性、取值、编号都和原版一致
- 区块存储从 8 位换成 16 位（全局状态编号）
- 地物写出正确的状态，和原版存档按完整状态（带属性）逐格对照
- 光照属性、纹理按状态取

JSON 方块模型（楼梯、台阶、栅栏、滴水石锥的形状、珊瑚扇……）留到 v7.1。

## 过程

1. **状态定义从原版数据报告生成**：服务端 `--reports` 输出的 `blocks.json` 里有每个方块的属性、取值和全局 ID。
   `tools/vanilla/gen-states.py` 给我们用到的方块（102 种有属性）写 `src/terrain/stateDefs.json`。
2. **编号规则**（`src/terrain/states.ts`）：方块 b 的默认状态编号就是 b，其余状态排在所有方块后面。
   这样 v6 以前写 `BlockType.xxx` 的代码不用改，写进去的就是默认状态。同一个方块内部的顺序和原版状态 ID 一样
   （最后一个属性变得最快）。一共 2372 个状态，直接模式 12 位。
   两种属性不参与编号：水、岩浆的 `level`（v3 起流动的水就是单独的“方块”，名字里按原版规则还原），
   一直含水的方块（珊瑚……）的 `waterlogged`。
3. **存储换成 16 位**：原型、装饰、不压缩的方块、网格邻域、光照网格都从 `Uint8Array` 换成 `Uint16Array`。
   所有按方块查的表（实心、形状、纹理、流体、光照）扩展成按状态查，长度 = 状态数——代码里用状态去查表不会查错。
   TypeScript 的类型检查找出了所有要改的地方。
4. **对照工具按完整状态比较**：`diff.ts` / `diff-areas.ts` 同时统计“方块一致”和“状态也一致”，`STATES=1` 时按状态列出差别。
   基线：方块 99.6716%，状态 99.5005%。
5. **地物带属性**：配置里的方块状态（`{Name, Properties}`）以前只取名字，现在带上属性（洞穴藤蔓的浆果、粉红花簇的朝向和数量、
   蘑菇方块的面……一下子对上了一大批）。判断方块性质的函数（是不是实心、在不在标签里）先去掉属性再查。
   `randomized_int_state_provider` 真的写属性；`rotated_block_provider` 补上了随机轴（原来没消耗随机数）。
6. **树叶的 distance**：
   - 原版 `TreeFeature.updateLeaves`：树放完以后在这棵树的包围盒里从原木出发分桶广度优先
   - 第一次对照：森林里的树叶有一半比原版大 1。原因是盒子边上的树叶，原版会安排一次方块刻，
     刻到时 `distance = min(邻居) + 1`，变了再通知邻居……最后基本等于沿着树叶走到最近原木的步数
   - 用原版自己的方块验证这个假设：98.6% 的树叶就是全局最短路，剩下 1.4% 是没被刻到的
   - 实现成区块的“落定”（`settle.ts`）：需要周围 3×3 个区块，所以游戏里在算光照的那一步做，对照工具里用 3×3 个区块算
7. **其余状态**：藤蔓贴在哪一面（树干藤蔓、树叶垂藤、藤蔓地物）；发光地衣和幽匿脉络的面改成存在状态里
   （原来用一张临时的表，跨区块就丢了）；两格高植物的上半；雪下面的草方块 `snowy=true`；
   滴水石锥的粗细和朝向（base / middle / frustum / tip，连在一起时 tip_merge）；海带 age；竹子的叶子；
   海泡菜个数；珊瑚扇的朝向；紫水晶芽的朝向；大蘑菇菌盖的“皮”；花式橡树、樱花树横着的树枝的 axis；
   化石骨块的 axis（转 90° 时 x、z 互换）；紫颂植物的连接；末地柱铁栏杆的连接；地牢箱子的朝向；
   可可果；垂吊苍白苔藓的 tip；幽匿尖啸体 can_summon；嘎枝之心；气泡柱的 drag（灵魂沙上是 false）；蜂巢朝南
8. **光照按状态**：`gen-light.py` 改成按我们的每个状态在原版状态表里查。有浆果的洞穴藤蔓发光 14，
   海泡菜 1~4 个分别是 6 / 9 / 12 / 15，没有面的发光地衣不发光，含水的方块挡 1 级光。
9. **纹理按状态**：横着的原木两头是年轮；雪地草方块的侧面；蘑菇方块没有“皮”的面是里面的颜色；
   有浆果的洞穴藤蔓；两格高的花下半格只有茎和叶；雪层按 layers 的厚度；多面方块按状态里的面画。
10. **游戏里**：放原木时按点的那一面定朝向；F3 的“准星”一行显示完整状态。
