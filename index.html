mc-replica · 逐版复刻 Minecraft Java 1.21.4

TypeScript + three.js。每个版本移植原版的一个系统，配一个能玩的 demo 和一篇技术文章；世界生成、光照、方块状态都拿原版服务端生成的存档逐格核对。

在线 demo 是公开版：地形用的是仓库自带的简化 demo 地形，纹理是程序画的，不包含任何 Mojang 的数据和素材。想看到和原版逐格一致的地形与原版外观，请克隆仓库，按 README 放入你自己 1.21.4 客户端里的数据后本地运行。
